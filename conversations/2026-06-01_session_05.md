## 2. AI actions in this session (chronological, summarised)

### 2a. Implement the fixed-point primitives

1. **`signals.py`** — implemented `class_redemption_probability` (Φ((s* − θ)/σ)), `posterior_mean_theta` (returns the signal itself in the improper-prior limit; full Bayesian update in the informative-prior case), `posterior_variance_theta`.
2. **`secondary.py`** — implemented `effective_depth` (M̃ = M / (1 + ζU/M)) and `secondary_price` (the full bounded formula from MODEL.md §3).
3. **`payoffs.py`** — implemented `redemption_payoff` (V_R = primary_share + (1 − primary_share)·p_sec − φ), `hold_payoff` (V_H = θ − c_q·q + ω), `aggregate_demand` (D = Σ_k W_k · Φ((s*_k − θ)/σ_k)), and `expected_indifference_gap` using Gauss-Hermite quadrature (`scipy.special.roots_hermitenorm`) on the improper-prior posterior N(s*_k, σ_k^2). Default 25 nodes.
4. **`fixed_point.py`** — implemented `logistic_warm_start` (class-specific scalar driven by reserve ratio, congestion and convenience yield) and `solve` (`scipy.optimize.root(method='krylov')` on the K-vector gap, with a damped fixed-point iteration fallback). Returns a fully populated `DrawResult`.

### 2b. Unit tests

5. **`tests/test_primitives.py`** — 14 tests covering signals, secondary, payoffs and aggregate_demand. Tests include: posterior mean reduces to the signal in the improper limit; depth erodes monotonically with unmet demand; secondary price is bounded in [p_underbar, 1]; demand at equal-threshold theta is exactly half the total stake; demand is monotone decreasing in theta; the indifference gap crosses zero between s*_k = −2 and +2.
6. **`tests/test_fixed_point.py`** — 6 tests for the solver. The first run failed two tests:
   - `test_tighter_reserves_raise_thresholds` failed because the model actually produces the **opposite** sign: tighter reserves increase unmet demand, which lowers the secondary price, which lowers V_R, which makes the marginal agent prefer to hold. The test was renamed to `test_tighter_reserves_dampen_demand_via_secondary_penalty` and the failing assertion was reversed. This pins down the Ma-Zeng-Zhang (2025) mechanism inside our model as a unit test, so a future refactor that breaks it would be caught.
   - `test_stubs_raise_not_implemented` in `test_smoke.py` failed because the stubs it asserted had been implemented in this session. Renamed to `test_remaining_stubs_raise_not_implemented` and updated to cover only `montecarlo`, `calibration` and `cost_benefit`.
7. Second pytest run: **26 passed in 6.66 s.**
