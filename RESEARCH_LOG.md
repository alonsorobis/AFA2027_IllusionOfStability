## 2026-06-01, session 05 — science layer opens

Implemented the Morris-Shin K-dimensional fixed-point solver in `simulation/stablecoin_ms/`. Five modules went from stubs to working code: `signals.py`, `secondary.py`, `payoffs.py`, `fixed_point.py`; `agents.py` and `issuer.py` had already been implemented as identities in session 02. The expected indifference gap is integrated against the improper-prior posterior using a 25-node Gauss-Hermite quadrature. The solver uses `scipy.optimize.root(method='krylov')` with a logistic warm start and a damped fixed-point fallback. Twenty-six unit tests pass (`tests/test_primitives.py`, `tests/test_fixed_point.py` and the smoke-test).

**Comparative-statics behaviour flagged by the test suite.** The original `test_tighter_reserves_raise_thresholds` was written assuming that tighter primary reserves should mechanically raise redemption demand. The first pytest run rejected that intuition: with R tightened from 1.0 to 0.2, aggregate demand actually drops from 0.487 to 0.426 because unmet demand spills to a less-liquid secondary market, the secondary price falls, V_R drops, and the marginal agent prefers to hold. The test was renamed to `test_tighter_reserves_dampen_demand_via_secondary_penalty` and the sign was flipped, so the model's comparative static is pinned by the unit suite. The same direction is reported by Ma, Zeng and Zhang (2025) in their two-layer setup; it is consistent with their interpretation and will be cited that way in the lit-review section.
