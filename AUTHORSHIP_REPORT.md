Per the AFA 2027 call, the submission must include a report showing the fraction of project lines (code, writing, documentation) created by humans versus AI. This file maintains a running tally and is refreshed after each substantive change.

## Counting rules
- **Unit:** lines (LaTeX, Python, Markdown), counted with `wc -l` equivalent.
- **Author class:**
  - `H` — written by the author directly (typed in editor, no AI suggestion accepted verbatim).
  - `AI` — produced by an AI assistant (Claude Code or other), then accepted verbatim or with cosmetic edit only.
  - `H+AI` — author rewrote AI output substantively (more than a one-line change). Counted as `H` for attribution but flagged in the audit column.
- **Scope:** everything under `AFA2027_IllusionOfStability/` except `conversations/` (those are evidence, not project output) and `data/raw/` (third-party data).
- **Refresh cadence:** at the end of each working session, the author or the AI assistant re-runs the count and appends a snapshot row.
